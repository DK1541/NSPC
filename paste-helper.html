2 Upload the photographs

Squarespace has no file browser, so images need a home before pages can point at them.

  1. Add a blank page called Image Library and leave it out of the navigation.
  2. Add an Image Block for each file in pages/home/images/, upload it.
  3. Publish, view the page, right-click each image → Copy image address.
  4. Keep those URLs somewhere — you'll paste them over the placeholders marked PHOTO SLOT in the page code.

The hero.jpg in every page folder is a stock landscape standing in for a real photograph. They're there so layout can be judged. Don't upload them.

Images uploaded, URLs collected
