# North Shore Presbyterian — Shared Kitchen

Single-page site for the Shared Kitchen ministry, styled to the official Shared Kitchen
brand deck (navy / coral / teal / gold, Poppins + Mulish, pineapple logo, overlapping-circles
motif). Adapts automatically to light and dark mode; all content is visible without JavaScript.

## Contents
- `index.html` — the page (no build step)
- `images/` — approved photos + NSPC logo

## View locally
Open `index.html`, or serve the folder: `python3 -m http.server 8000`

## GitHub Pages (optional hosting)
Settings → Pages → Source: `main` / root → live at `https://<username>.github.io/<repo>/`.

## Squarespace note
Relative image paths work on GitHub Pages / local hosting. To paste into a Squarespace
Code block, use the self-contained version (images embedded as base64) instead.
